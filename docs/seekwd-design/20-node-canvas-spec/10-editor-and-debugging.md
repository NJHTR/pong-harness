# 编辑器与调试交互

## 画布编辑区

编辑器至少提供：

```text
节点库和能力搜索
画布树和面包屑
节点、端口、边和分组
小地图、缩放、对齐和自动布局
类型错误、断链、循环和权限告警
草稿 / 版本 / 差异视图
```

坐标、颜色、折叠和个人布局属于展示数据，不进入运行语义。

## 节点检查器

检查器按节点定义动态生成，显示：

```text
责任和非目标
输入输出端口
配置字段及来源
环境与权限需求
主体选择
超时、重试、缓存和副作用
验证标准
内部图入口
版本与信任等级
```

不应为每一种节点硬编码一套互不一致的编辑器。

## 运行面板

运行面板显示图级、画布级、节点级和 Attempt 级状态：

```text
状态时间线
当前就绪队列
等待原因
活动权限请求
实时日志和流输出
输入 / 输出 Artifact
验证结果
父子运行关系
GraphPatch 差异
```

## 单节点调试

用户可以选择历史输入、替换某个输入、设置断点、单步运行、查看端口值、查看证据、重试 Attempt 或将结果固定为测试夹具。调试运行必须标记为 Debug Run，不得误写正式运行结果。

## 链路和子图调试

支持从任意节点开始重放下游；对于复合节点和 Agent 节点，可以进入内部图逐步调试，也可以只看聚合摘要。跨画布调试显示父子 Run、输入映射和返回事件。

## 人工接管

运行面板提供“接管当前节点”“交还 Agent”“锁定后续修改”“批准单个 Patch”等操作。接管期间的输入和结果使用正常 NodeRun 记录，并显示执行主体。
