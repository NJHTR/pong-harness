# 安全实现

## 本地会话

Workbench 使用 Host 创建的短期 Session；Session 与本机用户、客户端实例和工作区绑定。权限由 Host 重新评估，不能因为前端隐藏按钮就认为没有风险。

## 秘密管理

业务数据只保存 SecretRef；SecretResolver 在执行上下文准备时按最小范围注入，并在释放时清理。日志、崩溃报告、Artifact、记忆和 GraphPatch 禁止出现秘密明文。

## 扩展隔离

未知或未验证扩展默认在更强隔离和有限网络范围运行。扩展的读写、进程、网络、资源、Artifact 和能力调用都由 Policy 控制。

## 输入信任

用户文本、Artifact 内容、外部事件、模型输出和扩展返回都属于数据，不自动变成系统指令。指令来源和数据来源在 Context Packet 中分开标记。

## 审计完整性

关键授权、图补丁、运行终态和产物交付事件使用追加式记录和完整性校验。删除普通日志不能删除审计事实的引用。
