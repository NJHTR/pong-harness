# 缓存、检查点与幂等节点

## `cache.read`

根据显式 CacheKey 读取此前已验证结果。CacheKey 至少由节点定义版本、规范化输入、关键配置、上下文版本和策略允许的环境特征组成。

缓存命中必须验证 Artifact 可访问、未过期、Schema 兼容、敏感度可用和结果仍适用于当前成功标准。

## `cache.write`

保存 NodeResult 或 ArtifactRef 供复用。只能缓存定义为可缓存的输出；秘密、未验证结果、含临时外部句柄的结果和副作用确认不完整的结果默认不可缓存。

## `checkpoint.create`

在明确边界保存可恢复状态：图版本、已完成 NodeRun、输入输出引用、队列、等待、权限决定、外部句柄和迭代状态。检查点本身有版本和完整性校验。

## `checkpoint.restore`

从指定检查点创建恢复分支。恢复前检查画布版本、授权、Artifact、外部句柄和新鲜度；不能直接恢复到已不可用或语义不兼容环境。

## 幂等键

`idempotency.key` 可作为标准配置或运行输入。幂等键的作用域必须明确为节点、画布、目标或外部动作，不能在无关目标间复用。

## 缓存与重放区别

缓存复用结果，不执行节点；重放重新执行逻辑或从事件重建状态。两者都必须在 UI 与审计中明确显示，避免把旧结果误认为新执行。
