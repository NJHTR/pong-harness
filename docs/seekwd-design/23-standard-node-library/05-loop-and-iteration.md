# 循环、迭代与批处理节点

## 循环必须显式

所有循环都必须有入口、迭代状态、退出条件、上限、取消语义和结果汇聚策略。普通数据或控制边不能形成隐式循环。

## `loop.for-each`

对有限集合逐项或并行处理。实例声明迭代元素 Schema、顺序、最大元素数、并发、元素失败策略和输出顺序。

## `loop.while`

先执行迭代体，再求值退出条件，或按定义先求值。两种语义必须由节点版本固定，不能由 UI 猜测。条件读取迭代状态和声明输入，不能读取隐式全局状态。

## `loop.batch`

把集合分割为有限批次。节点声明批大小、最后一批行为、批间并发、批内错误、部分结果和重试粒度。

## `loop.retry-until`

用于“执行并验证，未通过则再次执行”的闭环。它与错误重试不同：每轮都会产生验证结果，退出条件必须是成功标准或明确失败条件。

## 迭代状态

```text
iteration index
input item / batch reference
accumulator
previous result
failure collection
exit decision
```

迭代状态按 Loop Node 的作用域隔离；恢复时从检查点继续，不重新猜测已经处理的元素。

## 终止性

上限可以是次数、时间、成本、资源、无进展轮数或组合条件。达到上限时输出结构化的 `limit_reached`，不能伪装为成功。
