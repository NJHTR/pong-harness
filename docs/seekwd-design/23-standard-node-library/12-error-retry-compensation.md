# 错误、重试、降级与补偿节点

## `error.catch`

接收结构化错误，按类别、严重度、来源、可重试性和作用域路由。没有匹配 Catch 的错误上升到画布或目标错误策略。

## `error.raise`

主动产生明确的 StructuredError，用于发现违反前置条件、业务规则或不安全状态。不得用普通文本输出代替错误信号。

## `retry.run`

重试指定可重试节点或子图。配置包括最大次数、退避、抖动、重试前刷新、输入是否重算、幂等要求和停止条件。

对于有副作用节点，Retry 必须先确认前一次结果是否未知；结果未知时转为对账、补偿或人工处理。

## `fallback.select`

在候选替代路径中选择一个，比较契约兼容、权限、质量、成本和信任。选择必须产生 DecisionRecord 和 Binding Revision。

## `compensation.run`

执行定义过的补偿节点或子图。补偿失败不掩盖原错误，输出单独的补偿状态和证据；之后由 Graph 策略决定停止或前向修复。

## 错误传播

节点错误默认只阻断依赖它的必需下游，而不是全局停止。画布级失败由显式 Error Path、质量门和目标成功标准决定。
