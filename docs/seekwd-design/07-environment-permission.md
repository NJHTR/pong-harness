# 执行环境与权限

## 执行位置与环境分离

节点的能力与在哪里运行是两个独立概念。

```text
执行位置：当前会话、工作区、本机、隔离上下文、外部上下文
环境：运行时、依赖集合、资源集合、凭据集合和工具集合
```

节点声明需求和首选位置，调度器选择可用环境；没有满足条件时进入 `waiting_environment`。

## 权限范围

```text
filesystem.read / filesystem.write
outside_workspace.read
network.access
process.execute
environment.install
docker.run
remote.ssh
external_agent.call
secrets.read
```

权限应绑定到节点、画布、运行、工具调用和具体资源范围，不能只用一个全局布尔值。

## 模式

- **手动模式**：Agent 只能提出图变更和操作，用户逐项批准。
- **协作模式**：低风险观察和沙箱动作自动执行，高风险动作审批。
- **全权代理模式**：在用户明确授权的资源、环境和预算范围内自动执行。

切换模式前应暂停当前运行，保存检查点，明确新模式作用于后续动作还是整个运行。

## 高风险边界

未知外部操作、环境变更、超出工作区的资源、凭据、外部传输、删除性操作和长期后台任务都需要显式范围、审批和审计。
