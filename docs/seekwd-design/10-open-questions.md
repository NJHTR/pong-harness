# 待确认问题

这些问题不阻止继续整理方案，但在进入详细实现前需要确定。

1. 本地 Agent Host 的实现形态和生命周期如何定义？
2. 不同操作系统与外部环境的交互能力如何抽象和适配？
3. 执行单元之间采用单一协议、协议适配层还是能力协商模型？
4. Artifact 存储使用文件系统、数据库、对象存储还是混合方案？
5. 图版本采用分支模型，还是不可变版本图？
6. 全权代理模式的默认资源范围、预算和最长运行时间如何定义？
7. 用户是否允许 Agent 自动把成功运行发布为技能，还是必须逐项确认？
8. 外部 Agent 的身份、凭据、沙箱和取消语义如何统一？
9. 代码节点是否允许编译器、包管理器和网络访问？默认应否完全隔离？
10. 主画布、运行时临时图和能力实验画布的 UI 是否使用同一套编辑器？
