# 核心能力完成定义

## 目标

完成标准：Goal 可版本化；原话、约束、假设和成功标准可查看；修改不会破坏历史 Run；缺失关键标准不能标记成功。

## 画布和节点

完成标准：可以创建、编辑、校验、发布和调用版本化画布；节点、端口和边有 Schema 校验；复合节点可展开和封装；错误图不能运行。

## 运行时

完成标准：可调度并行依赖；支持等待、暂停、取消、检查点、重试和恢复；每个 NodeRun 都有输入输出、主体、上下文和状态事件；副作用不重复执行。

## 人机协作

完成标准：人类和 Agent 都能建图和执行；可在节点级交接；人工结果进入同一验证链；Agent 变更以可预览 Patch 出现。

## 能力与扩展

完成标准：能力可以注册、发现、匹配、绑定、健康检查和取消；无能力时产生 CapabilityGap；新能力经过契约和验证后才可发布。

## 安全

完成标准：所有副作用前都经过 Policy；审批绑定具体动作；撤销、过期和拒绝会阻断后续执行；日志和 Artifact 不泄漏秘密。

## 可追溯性

完成标准：可以从交付物追溯到目标、画布版本、节点运行、输入、执行上下文、权限决定和验证证据；也能从失败节点找到受影响的目标。

## 发布门槛

一个版本只有在契约测试、状态机测试、故障恢复测试、权限测试、图属性测试和关键端到端场景通过后，才可被标记为可用于真实目标。
