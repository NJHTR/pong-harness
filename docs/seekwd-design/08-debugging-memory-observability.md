# 调试、证据、记忆与技能沉淀

## 三种调试粒度

- **节点调试**：替换输入，仅重跑一个节点。
- **链路调试**：从选定节点开始重放下游，复用已确认输出。
- **子图/跨画布调试**：进入 Agent、复合节点或目标画布内部逐步执行。

节点运行必须保存：

```text
输入快照、输出 Artifact、日志、截图或观察结果、环境版本、执行位置、权限记录、耗时、成本、GraphPatch、错误和重试关系
```

## 证据模型

结论应引用可复核证据：资源定位、状态快照、内容片段、执行输出、外部执行单元返回、测试报告或人工确认。证据要有时间、来源、作用域和完整性标识。

## 记忆分层

```text
Run Memory        当前运行的临时上下文
Workspace Memory  当前项目的文件、约束、工具和用户偏好
Skill Memory      已验证可复用的节点、适配器和复合画布
User Memory       用户明确允许长期保存的偏好
```

所有记忆可查看、编辑、删除和禁用；不能把外部网页内容或一次偶然成功自动写成永久事实。

## 技能沉淀

```text
一次执行轨迹
  -> 清理敏感数据
  -> 抽象输入输出契约
  -> 生成回归测试
  -> 运行验证
  -> 发布为 experimental / verified 技能
```
