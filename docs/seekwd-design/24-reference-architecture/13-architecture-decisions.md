# 参考架构决策

## A-001：Workbench 不是运行时事实来源

Workbench 可以展示、编辑和发起命令，但 Goal、Graph、Run、Policy、Artifact 和 Audit 的事实由 Host / Core 持久化管理。

## A-002：Host 是本地控制边界

本地能力、持久化、调度、权限和扩展由 Host 统一协调。外部执行上下文不能直接连接 UI 或互相读写私有状态。

## A-003：控制平面与执行平面分离

NodeRun 通过 Executor Contract 执行；执行器返回结果、观察和句柄，不直接改写图、目标或授权事实。

## A-004：长期任务不依赖客户端存活

Workbench 关闭不会默认取消 Run；恢复依赖持久化事件、检查点和外部状态对账。

## A-005：扩展通过契约接入

领域能力、Agent、执行器和画布包不直接修改核心存储，必须使用版本化 Manifest、命令、事件和执行协议。

## A-006：技术选型服从语义契约

技术选择必须满足本目录、基础规范、节点画布规范和目标执行规范；不能为了迁就某个框架而重新定义版本、事件、权限或恢复语义。
