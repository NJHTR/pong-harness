# 网络与远程边界

## 网络不是默认能力

每个执行上下文默认拥有最小网络能力。节点、能力和扩展声明需要访问的目标类别、方向、协议、数据敏感度和最大流量；Policy 决定是否允许。

## 数据出境

将 Artifact、日志、上下文或秘密引用传出当前设备、工作区或信任域前，必须经过数据出境策略。策略可允许摘要、脱敏副本或特定字段，而不是只有允许/拒绝两种状态。

## 远程调用

远程执行使用 Remote Operation Handle，并记录远程主体、目标上下文、凭据引用、版本、请求摘要、取消能力和结果确认。网络断开时，结果状态可能未知，父 Run 必须等待对账或人工处理。

## 回调和事件

外部回调需要验证签名、关联 ID、版本、时间窗口和去重键。未经验证的回调只能作为未信任观察，不能直接触发有副作用节点。

## 凭据

Host 只向需要的执行上下文提供短期、最小范围凭据引用。凭据值不进入 GraphVersion、Run Event、日志、记忆或普通备份。

## 网络不可用

离线时，本地可运行节点和草稿编辑继续；依赖网络的节点进入 waiting_dependency 或明确失败。恢复联网后，系统重新检查凭据、版本、策略和数据新鲜度，再决定是否继续。
