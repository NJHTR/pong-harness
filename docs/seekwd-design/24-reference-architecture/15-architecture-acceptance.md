# 参考架构验收

## 拓扑验收

- Workbench 关闭后，Host 能继续维护并恢复活动 Run。
- 执行上下文崩溃不会直接破坏 Goal、Graph 或 Policy 事实。
- 第二个客户端连接已有 Host 时不会产生并发写入冲突。

## 数据验收

- 画布版本、运行快照、Artifact revision、Evidence 和审批可以互相追溯。
- 存储投影删除后可以从事实重建。
- 升级中断后能恢复到明确的 migrating 或 recovering 状态。

## 协议验收

- 客户端断线重连不会丢失关键事件。
- 重发命令不会重复创建副作用。
- 未知协议字段和版本不兼容会安全拒绝或进入只读模式。

## 安全验收

- 执行器无法获得未声明资源或权限。
- 扩展无法直接修改核心事实。
- 日志、诊断包、备份和错误响应不会泄露秘密。

## 运行验收

- 节点排队、等待、暂停、取消、恢复和孤儿处理都有持久化状态。
- 外部结果未知时不会自动重复副作用。
- 资源超额会产生可解释的等待或失败，而不是无界消耗。

## 用户验收

- 用户可以从目标进入画布、节点、Run、证据和产物，再反向追溯。
- 用户可以在任意节点切换人类、Agent 或协同控制。
- 用户看到的是可解释的状态和原因，而不是只看到加载动画。
