# 观察、证据与验证

## 观察对象

观察是对环境或运行状态的结构化记录：

```text
Observation
  subject
  observed value or state
  source
  scope
  observedAt
  freshness
  confidence
  integrity
```

观察结果只描述“看到或收到什么”，不直接等于目标结论。

## 证据与结论

```text
Evidence      可复核的观察、输出、文件或人工确认
Claim         Agent 或验证器提出的判断
Verification  将 Claim 与 Evidence、成功标准关联
```

每个成功标准都要绑定一个或多个验证器。验证器可以检查结构、状态、内容、质量、测试、用户确认或其他可定义谓词。

## 验证层级

- **结构验证**：类型、格式、必需字段和引用存在。
- **状态验证**：环境或外部对象达到目标状态。
- **行为验证**：执行动作产生预期行为。
- **质量验证**：结果达到明确阈值。
- **一致性验证**：多份结果之间没有冲突。
- **人工验证**：用户确认无法自动判断的标准。

## 验证失败

验证失败要返回结构化信息：失败标准、证据、差距、可能原因、可修复性和建议动作。只有“失败”没有差距说明，Agent 无法可靠修复。

## 新鲜度

外部状态、文件和服务结果都可能过期。每个证据声明有效时间和刷新方式；恢复运行或跨画布等待后，必要时重新观察。
