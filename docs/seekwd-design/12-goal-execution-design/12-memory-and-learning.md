# 记忆与能力沉淀

## 记忆分层

```text
Run Memory        当前运行的临时事实、观察和决策
Goal Memory       当前目标的约束、偏好和历史计划
Workspace Memory  当前工作区的结构、规则和用户明确偏好
Skill Memory      已验证可复用的能力、节点和复合图
User Memory       用户允许跨工作区保留的长期偏好
```

每条记忆都要保存来源、时间、作用域、可信度和过期规则。没有来源的生成内容不能自动成为事实记忆。

## 记忆读写流程

```text
收集候选事实
  -> 去重和冲突检测
  -> 敏感信息检测
  -> 判断作用域和保留时间
  -> 按策略写入
  -> 检索时过滤权限和新鲜度
```

用户可以查看、编辑、删除和禁用记忆。Agent 不能通过记忆绕过当前运行权限。

## 技能沉淀

一次成功运行可以被抽象为技能：

```text
运行轨迹
  -> 删除敏感数据
  -> 抽象稳定输入输出
  -> 移除偶然步骤
  -> 生成回归样本
  -> 验证可重复性
  -> 发布候选技能
```

技能必须说明适用范围、前置条件、失败边界、信任等级和版本。工作区技能优先于全局技能，但不能覆盖安全策略。

## 反馈学习

用户的修改、拒绝、接管和评价都可以作为反馈信号，用于改善未来规划；反馈不能直接改变已经发布的节点版本，必须经过新的验证流程。
